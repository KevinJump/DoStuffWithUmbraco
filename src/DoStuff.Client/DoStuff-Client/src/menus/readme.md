# Menu Items

When know what the elements in the menu are going to be in your menu.
For example if you have some pre-defined views you want to organise into a list

A core example of this would be in the settings section, stucture, templating and advanced
are all well known and the elements beneath them are the same all the time.

If you want something dynamic that depends on data, then you need to impliment a tree
menu, (just like the content or media section). these are more complex, so where possible
you should try to use a simple well known tree, if that's what you need.
